# OGIPOS Laundry - Landing Page

Landing page profesional untuk OGIPOS Laundry, aplikasi kasir laundry berbasis web dengan lisensi sekali bayar.

## Fitur Landing Page

### 1. Navbar Responsif
- Logo OGIPOS
- Menu navigasi: Fitur, Bandingkan Biaya, Harga
- Tombol Masuk dan Coba Gratis
- Mobile menu dengan hamburger icon

### 2. Hero Section
- Headline utama dengan highlight "Bayar sekali, pakai seterusnya"
- Deskripsi produk
- Tombol CTA: Coba gratis sekarang, Lihat semua fitur
- Preview Dashboard Owner dengan mockup interaktif
- Trust badges: Berbasis web, Milik Anda selamanya, Ringan dan stabil

### 3. How It Works
- 4 langkah mudah: Daftar, Setup, Aktivasi, Beroperasi
- Icon visual untuk setiap langkah
- Layout responsif

### 4. Features Section
- Dashboard Owner dengan 6 fitur utama
- Card layout dengan icon
- Hover effects

### 5. Testimonials
- 3 testimoni dari pengguna
- Rating bintang
- Informasi bisnis dan lokasi

### 6. Kalkulator Penghematan
- Input biaya langganan bulanan
- Slider periode 1-10 tahun
- Perhitungan otomatis penghematan
- Format Rupiah Indonesia
- Visualisasi perbandingan

### 7. Pricing
- Harga lisensi lifetime: Rp 99.000
- 12 benefit fitur
- Tombol CTA: Coba Gratis, Lihat Demo
- Badge "Terpopuler"

### 8. FAQ
- 9 pertanyaan umum dengan accordion
- Smooth animation
- Responsive design

### 9. CTA Section
- Call-to-action dengan background gelap
- Trust badges

### 10. Footer
- Logo dan deskripsi
- Menu navigasi
- Menu produk
- Informasi kontak

## Teknologi

- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Fonts**: Inter (Google Fonts)

## Warna

- **Primary**: Teal/Tosca (#0d9488)
- **Text**: Slate (#1e293b, #475569, #64748b)
- **Background**: White (#ffffff), Slate-50 (#f8fafc)
- **Accent**: Amber, Blue, Purple untuk variasi

## SEO

- Meta tags lengkap (title, description, keywords)
- Open Graph tags
- Twitter Card
- Canonical URL
- Structured data (JSON-LD)
- Semantic HTML
- Sitemap.xml
- Robots.txt

## PWA Ready

- Manifest.webmanifest
- Favicon SVG
- Apple touch icon

## Responsif

Breakpoints:
- Mobile: 320px - 640px
- Tablet: 641px - 1024px
- Desktop: 1025px+

## Performa

- Bundle size: ~185KB (JS) + ~24KB (CSS)
- Gzip compressed: ~55KB (JS) + ~5KB (CSS)
- Lazy loading ready
- Optimized images
- Smooth animations

## Cara Menjalankan

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build
npm run build

# Preview production build
npm run preview
```

## Struktur File

```
src/
├── App.tsx          # Main component dengan semua section
├── main.tsx         # Entry point
├── index.css        # Global styles & Tailwind config
public/
├── favicon.svg      # Favicon
├── manifest.webmanifest  # PWA manifest
├── robots.txt       # SEO robots
├── sitemap.xml      # SEO sitemap
```

## Catatan Penting

1. **Warna**: Menggunakan warna bawaan Tailwind (slate, teal) untuk kompatibilitas maksimal
2. **Icons**: Lucide React untuk icon profesional
3. **Animasi**: Smooth dan tidak berlebihan
4. **Accessibility**: Semantic HTML, ARIA labels
5. **Performance**: Optimized bundle size, lazy loading ready
